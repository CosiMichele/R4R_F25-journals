## Research Application

> [!IMPORTANT]
> **Due Monday 15th, 11pm**

Data management is a critical, yet frequently overlooked, component of research projects. If not properly addressed, it can become a significant issue that not only makes the research process more difficult but also causes delays or makes its reproducibility challenging. My research, which focuses on hydroclimate extremes, involves using diverse data types, including numeric data like meteorological variables (e.g., temperature and precipitation), and complex models and computer code, such as weather and hydrological models. Therefore, applying a structured approach to data management throughout the entire data life cycle—from planning and collection to analysis has been a frequent practice. While my current projects maintain a practice of using personal notes for reproducibility, moving towards a more thorough implementation of comprehensive project documentation, which includes rich metadata, is crucial for fostering reproducibility and accessibility that benefits broader scientific and public communities. Therefore, implementing the use of public repositories like GitHub can be a strategy, not only for maintaining open-access code but also for hosting robust documentation.

## Cohort meetup discussion

> [!IMPORTANT]

> **Due Thursday 18th, 11am**

This week's discussion centered on cohort members' diverse personal experiences with data management practices across various fields. Participants shared insights into using data for qualitative and quantitative analysis, their storage methods, and approaches to sensitive data handling. Another theme explored was the need for a comprehensive data management strategy that spans the entire data life cycle. For my research, a particularly valuable insight was that it may not be necessary to preserve all data. Given  that some data undergoes many steps of analysis, quality control, etc., selectively saving data with value, rather than attempting to save everything, is a practical consideration for effective long-term management.
