## Research Application

This week’s session showed me that version control is more than just a technical tool, it’s a mindset for reproducible science. By learning Git and GitHub, I can ensure that every change I make to code or documentation is recorded, reviewable, and restorable. In biomedical engineering, reproducibility is vital because small coding errors or undocumented data changes can affect experiment outcomes. Using commits, README files, and clear branching strategies can make my projects easier to verify and continue in the future. Moving forward, I plan to integrate GitHub into my regular workflow, not just for programming, but as a foundation for transparent and collaborative scientific research.
